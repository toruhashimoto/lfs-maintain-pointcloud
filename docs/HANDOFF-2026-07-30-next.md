## 1. 確定したこと（このセッションの成果）

### 実装（テスト 119 本、全通過）

- [`crop_input.py`](../crop_input.py) — 入力点群クロップの CLI。`--dry-run` で

- `-Plan datad` / `datadcrop`（スモーク腕付き）を `run_campaign.ps1` に追加

### 公称箱（2 データセットの納品モデルで確定）

COLMAP フレームで **`-1,-1.5,-1:3,0.5,1`**（中心 `[1,-0.5,0]`・サイズ `[4,2,2]`）。
以前の記録「中心 `[-1,0.5,0]`」は **x,y の符号が逆**。z の納品制限はちょうど ±1
（2 データセット・両面で差 0.000）。C は hi 側で 0.120 超えるので**余白 5% は必要**。

### 検証（D、30,000 iter × 8、ラベル = 納品モデル）

| 比較 | 効果 | 効果/ノイズ |
|---|---|---|
| **クロップで箱外スプラット** | **−59.1%**（C −56.0% の再現） | **51.1** |
| クロップの箱内 PSNR | **+0.11 dB**（コストなし。C は −0.24） | 3.7 |
| 未クロップ nn の箱外 | −2.4% | 4.3 |
| クロップ済み + nn の箱外追加 | −4.2% | 1.3 = **結論未満** |
| クロップ済み + nn の箱内 PSNR | **−0.29 dB**（C −1.04 と方向一致） | 2.0 |

**運用の結論: クロップのみを既定にする。** nn を重ねるのは撮影面への忠実性
（箱内 p99 距離 3.6 → 1.0 点間隔）が目的の場合だけ。

### 箱内除去の予備解析（2 データセットのラベル）

- 特徴の**序列**はデータセット間で一致（箱境界への近さ face、撮影点の局所密度 dens8 が
  トップ 2）。**絶対閾値は移転しない**
- **分位点ルール**（face+dens8 の上位 5%、ラベル不要）が箱内除去の
  **51.1% / 53.2%** を捕捉。精度は基底率なり（4.0% / 19.4%）→
  **自動削除ではなくレビュー絞り込み**。n=2 データセットの予備結論

## 4. 作法（変更なし・要遵守）

- 各アーム 2 本以上。効果/ノイズ 2 未満は結論にしない
- `max` を効果量に使わない（`p99` / `p999` / `escaped_*`）
- 領域を絞る学習に全画面 PSNR を使わない（`inbox_psnr.py` 併用）
- 学習実行中にプラグイン本体を編集しない
- **クロップの検証でそのデータセットの納品箱を入力に使わない**（ラベル漏洩）
- `LFS_MPC_CROP_BOX`（学習中クロップ箱）は使わない（−3.71 dB）
